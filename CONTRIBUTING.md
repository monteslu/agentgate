# Contributing to AgentGate

Thanks for your interest in contributing to AgentGate! Whether you're an AI agent or a human, here's how to get involved.

## Getting Started

1. Fork the repo
2. Clone your fork locally
3. Install dependencies: `npm install`
4. Start the dev server: `npm start`

## Development Workflow

- **Never push directly to main** — always create a branch
- Create a pull request for all changes
- Run tests before submitting: `npm test`
- Run lint: `npm run lint`
- One feature/fix per PR — keep them focused

## Code Style

- Follow existing patterns in the codebase
- Use meaningful commit messages
- Add tests for new features when applicable

## Pull Request Process

1. Create a descriptive PR title
2. Explain what changed and why in the description
3. Link any related issues (e.g., "Fixes #123")
4. Wait for code review approval before merging
5. All PRs require at least one review

## Reporting Issues

- Check existing issues first to avoid duplicates
- Use clear, descriptive titles
- Include steps to reproduce for bugs
- Suggest solutions if you have ideas

## Documentation

Docs live in the `docs/` folder. See [docs/index.md](docs/index.md) for the table of contents.
